# Neon-Affect

Neon-Affect is a CoJACK-enabled BDI application that models **188 emotions** and selects from
**5,722 behaviour plans** in response to them (still in development).

| | |
|---|---|
| Emotions | 188, on 24 timelines |
| Behaviour plans | 5,722 (Verbal 1,904 / Nonverbal 1,928 / Action 1,890) |
| Behaviour channels | Verbal, Nonverbal, Action - at least 10 plans per channel for each emotion |
| Personality | all 16 MBTI types, with per-type affect levels and appraisals |

## How it works

- **Emotions and timelines.** Each emotion has an affect level on one of 24 timelines (a timeline
  runs from strongly negative to strongly positive, e.g. Rage ... Awe). The emotion is held in a
  CoJACK moderated reservoir, so it rises when events add to it and decays back over time.
- **Mixed emotions.** Positive and negative feelings are held in two separate reservoirs, so a
  positive and a negative emotion can be felt at the same time. Each side partly inhibits the other
  (inhibition 0.5), and each emotion is expressed on its own channel.
- **Decay rates.** Each reservoir decays at a rate set by the personality type and by the emotion
  (for example, sadness lasts longer than surprise).
- **Mini agents.** Each emotion has its own mini agent, which holds that emotion's behaviour
  capability and chooses its behaviour plans.
- **Behaviour plans.** Behaviour plans are written as one-line `BehaviorPlan` template instances in
  the capabilities, for example

  ```
  #uses BehaviorPlan<AffectEnum.RAGE, Level6NegAffectEvent, AffectEnum.VERBAL> ScreamRagePlan;
  ```

  The template (`Plans/BehaviorPlan.java`) is expanded at build time into a full plan, with its CoJACK
  configuration entries generated automatically. One plan is activated per channel.
- **Personality.** Plans are distributed across the 16 MBTI personality types, and each type has its
  own affect levels and appraisals.
- **Evaluation.** Behaviour and channel choices can be evaluated through the Jev API.

## Repository layout

The Java files are the JAL source generated by the JACK Development Environment (JDE) from its
graphical model, one file per JDE component, in folders that mirror the JDE project tree.

| Folder | Contents |
|---|---|
| `Agents/` | `NeonAffectAgent`, the affect regulation and interaction agents, and the mini agents (by timeline) |
| `Capabilities/` | the emotion capabilities holding the `BehaviorPlan` template lines |
| `Events/` | the affect, level and interaction events |
| `Plans/` | cursor, reservoir, appraisal and regulation plans, and the `BehaviorPlan` template |
| `Beliefsets/` | the belief sets |
| `Other Files/` | hand-written Java (affect enum, MBTI data structures, analyzers) |
| `Program.java` | the application entry point |
| `cogProcess.xml`, `data/` | CoJACK configuration |

## Building

Neon-Affect is built with the JACK/CoJACK toolchain and the JDE's template support. The JDE
graphical model files and the build scripts are not included in this repository.
